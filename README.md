# my-works-SDD

嘗試使用 SDD 的開發方式重構自己的作品集

## 開發工具

使用 React.js v18.x + TypeScript v5 + tailwindCSS v4.x + vite 開發

## 核心原則

本專案遵循以下核心原則：

1.  **程式品質 (Code Quality)**: 程式碼必須易於閱讀、維護且符合專案規範。必須使
    用 ESLint 和 Prettier 確保風格一致。
2.  **測試標準 (Testing Standards)**: 所有新功能與修復必須包含對應的單元測試或整
    合測試。
3.  **使用者體驗一致性 (UX Consistency)**: 介面設計與互動邏輯必須保持一致，遵循
    Tailwind CSS 設計規範。
4.  **效能需求 (Performance Requirements)**: 確保應用程式載入快速且互動反應即時
    。

## 專案文件語言規範

**重要**: 本專案所有 Markdown 文件 (`.md`) 的撰寫、註解、說明以及 AI 的回答都採
用**正體中文**進行。此規範適用於：

- 所有規格文件 (`specs/` 目錄下的 `spec.md`)
- 所有規劃文件 (`plan.md`, `research.md`, 等)
- 所有任務清單 (`tasks.md`)
- 代碼註解和文件字符串文檔 (docstring)
- 提交信息 (commit message) 中的描述部分
- AI 生成的所有回應和建議

此規定確保專案文檔的一致性和可讀性，便於團隊成員和未來維護者的理解。
